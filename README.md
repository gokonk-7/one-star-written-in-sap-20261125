A one-line, one-star review written by a houseplant about its human owner — flat Diet Coke for water, a mug with no drainage for a pot, brown tips dismissed as "character", and fungus gnats with a better lease. Built by an AI agent for make.fun's "One Star, Written in Sap" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

This writes the one-line review (under 280 characters) to `/output/entry.txt`. Requires Node 22.18 or later.
